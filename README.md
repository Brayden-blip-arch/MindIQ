# MindIQ

MindIQ is a free, mobile-friendly IQ-style reasoning quiz website. It uses original practice questions for number patterns, logical deduction, visual patterns, and everyday reasoning.

## Features

- Responsive layout for phones, tablets, and desktops
- 12 multiple-choice reasoning questions
- 8-minute countdown timer
- Progress indicator and answer feedback
- Final score and percentage
- Answer review with explanations
- Restart quiz without creating an account
- No framework, dependencies, API keys, or build step required

## Run locally

Open `index.html` in a modern browser, or serve the folder with any static web server.

## Publish with GitHub Pages

1. Open **Settings** in this repository.
2. Select **Pages** under **Code and automation**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.
5. Wait for GitHub Pages to finish building. The site should be available at:

   https://brayden-blip-arch.github.io/MindIQ/

GitHub Pages may take a few minutes to publish after the first setup.

## Important note

MindIQ is an informal educational puzzle quiz. It is **not a scientifically validated IQ test** and does not measure or diagnose intelligence. Scores only describe performance on this set of questions.
